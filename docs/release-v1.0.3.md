v1.0.3 发布说明

一、市场数据改盘中实时（核心升级）
将市场温度 / 宽度 / 情绪周期从「盘后静态」升级为「盘中实时」，让盘中最常用的三块市场结构读数真正跳动。
- 市场综合评分：原盘后西财 13 维评分改为盘中实时合成（涨跌家数 22 分 + 涨跌停比 12 分 + 量能配合 6 分，0–60 量表）；集合竞价 / 交易 / 午休 / 收盘后当日显示「实时 / 午休 / 收盘」标签，交易时段每 60s 刷新。
- 市场宽度：新增「今日实时广度」（涨跌家数 / 涨停跌停 / 连板梯队），交易时段每 60s 刷新、收盘后冻结。
- 市场情绪周期：实时连板梯队（连板高度 / 首板 / 二板 / 晋级率）+ 盘中热度 + 今日主线，交易时段每 60s 刷新、收盘后冻结。
- 收盘后窗口修复：收盘后当日（15:00–24:00）保留今日盘中快照并标「收盘」，不再立刻回落盘后（根因：非交易时段回落盘后分会与上游 T+1 重算冲突，造成评分断崖）；盘前 / 周末 / 节假日回落盘后并标注「上一交易日收盘快照」，避免把冻结数据误认为实时。

二、新增宏观风向 + 黄金行情两张卡（蒸馏同花顺 skill）
将三个同花顺 skill 中可复用的功能蒸馏进面板（市场榜单 tab）。
- 宏观风向（标「盘后」，T-1 日更）：降息概率（最近议息会议区间命中概率，如 10-29 会议 375-400bp ×85.1%）、美债 10Y 实际利率、期限利差（10Y-2Y）、恐慌指数 VIX。
- 黄金行情（标「实时」）：伦敦金现 / 广发·民生·浙商积存金 / AU9999 / AUTD 共 6 个品种实时报价，带行情时间，夜盘持续更新；涨红跌绿符合国内惯例。
- 数据源失败时两卡自动隐藏，不影响其他模块；60s TTL 缓存降低请求压力。
