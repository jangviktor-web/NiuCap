v1.1.0 发布说明

本次更新的主题，一句话概括：**让面板「看得见」，也让结论「看得懂」。**

看得见，是给了它白昼与夜色两副面孔，也给市场装了一根 0~100 的温度计；
看得懂，是把量化里最晦涩的「因子」这件事拆成三步走通——先算清楚哪些指标真有用，
再把统计结论翻译成人话，最后把同一把尺子递到每一只股票手里。

此前「因子」对大多数使用者是一团黑箱：听说过动量、低波这些词，却不知道自己手上的
指标到底灵不灵，更不知道某只票当下处在什么位置。这一版把这三层全补上了。

一、因子实验室：IC / ICIR 因子检验（核心新增）

一句话：回答「哪些指标对 A 股未来收益真有预测力」。

- 12 个内置连续因子，六大类别
  · 动量：20 / 60 / 120 日动量
  · 反转：5 日反转
  · 低波：60 / 120 日波动率、60 日最大回撤
  · 超买超卖：RSI(14)、MA20 乖离、布林 %B
  · 流动性：60 日均成交额（对数）
  · 量能：5 日 / 60 日量比

- 检验怎么做
  · 构造「交易日 × 股票」因子矩阵，只用 t 日及之前的数据，无前视；
  · 未来收益取 close[t+1+forward] / close[t+1] - 1——t 日收盘出信号、t+1 收盘才买入，
    贴近实盘，避免「用信号日收盘价成交」这种只存在于回测里的完美假设；
  · 每个交易日做一次横截面 Spearman 秩相关，得到 IC 序列；
  · 汇总 IC 均值 / ICIR / IC>0 占比 / t 值 / 五档分层收益 / 市况分段
    （用成分股自构等权指数划分涨、跌、平，不依赖外部指数数据）。

- 三个刻意设计
  1) 方向不预设「越大越好」，一律由 IC 符号决定。这件事上数据说了算，不由人事先规定。
  2) 判定条件是「|ICIR| ≥ 0.3 且 q ≤ 0.1」两个条件同时满足。
     一次跑 12 个因子，就算全部无效，按 p<0.05 平均也会捞出 0.6 个「显著」——这就是
     多重检验。ICIR 单看分不清「真有 alpha」和「运气好」，所以加了 Benjamini-Hochberg
     FDR 校正，把「同时检验了 N 个」这件事折进 q 值。只满足 ICIR 不满足 q 的，不给 ✅。
  3) 数据不够就直接拒绝跑。池内有效截面不足 250 个交易日（约一年）时返回 409 并说明
     原因。理由是 ICIR 在样本不足时会给出一个看起来很正常的数字，用户没法从结果本身
     判断它是不是噪声；在入口处明说「不够」，至少知道该去补数据，而不是信一个假信号。
     宁可拒绝，不可糊弄。

- 入口：☰ 菜单 → 📈 分析 → 🧪 因子实验室
  · 股票池下拉直接标注每个池的「有效截面 N 日」，不够门槛的置灰不给选；
  · 默认只取近 750 个交易日（约 3 年）：全历史 3106 天跑 12 个因子的 IC 要几十秒，
    而几年前的 IC 对当下几乎没有参考价值。可在「回看区间」改 250 / 1500 / 全部历史；
  · 结果按（池、收益窗口、回看区间、是否分段）缓存 30 分钟，二次打开从 5.5 秒降到 0.07 秒。

二、因子实验室 · 一键 AI 解读（把结论说成人话）

检验表格对小白不友好——ICIR、q 值、分层单调性，每个词都得查一遍。控制条上的
「✨ AI 解读」把当前这份结果发给大模型，翻译成三样东西：

- 总览：这批因子整体有没有预测力，最值得关注的一两个是谁（必须引用给定数字）；
- 逐因子：这个因子在算什么、算出来的数说明什么、能怎么用；判定未通过的会明说
  「只适合观察、暂不宜当决策依据」；
- 注意点：使用前必须知道的事——样本期多长、市况变了可能失效、分层不单调说明
  预测力不稳定。

四个刻意的护栏（这些不是防御性编程，是防止自欺）：

1) 只喂前 5 个因子，且名字写进 prompt 逐个校验。
   后端先按 |ICIR| 降序取前 5 名，模型返回的因子名不在这份名单里，整份解读作废。
   少了这道，模型会自己挑因子、甚至编一个不存在的名字——而用户看不出区别。
   这是本模块最重要的一条护栏。
2) 所有数字必须来自传入的检验结果。模型的活是「翻译 + 解释怎么用」，不是「算数」。
   检验结果是确定性算出来的，不能反过来被模型改写。
3) 解读缓存命中不扣配额。同一份结果 30 分钟内的解读直接复用（标「缓存复用 · 未扣次数」），
   不重复花 Token；顺序上是先查缓存、再扣次数。
4) 失败绝不伪装成成功。模型未启用 / 网络错 / 输出不过 schema，一律降级并给出原因文案，
   页面照常可用，不报错、不白扣配额。

配额与「AI 深度分析」「小白选股讲解」共用同一池（默认 10 次/天，后台「AI 用量」可调），
模块开关 TICK_AUTH_REQ_FACTORAI 默认要求登录。

三、个股页 · 因子画像（把尺子递到每一只股票手里）

个股页新增「因子画像」卡片：同一批 12 个因子的当前值，以及该值在本股近 750 个交易日
中的历史分位。

**这里有一个必须说清的取舍：个股不做 IC。**

IC / ICIR 是横截面统计量——同一天把池子里几百只股票排名，看排名与未来收益排名的相关性。
单只股票只有一条时间序列，每期 1 个样本，IC 在统计上**无定义**。不是「算出来很差」，
而是根本算不出来。硬套只会产出一个看似专业、实则无意义的数字，而用户无从分辨。

所以这里换了个能算的问题：**这只票现在的因子值，相对它自己的历史处于什么水平。**

- 分位条只表达「位置」，不表达好坏。同一个 80% 分位，对低波因子是「波动比历史大」，
  对动量因子是「涨幅比历史强」，好坏取决于因子方向。颜色若带褒贬，就是误导。
- 方向容易读反的因子单独措辞。最大回撤是负值，分位 79% 的真实含义是「回撤比历史上
  79% 的时候更浅」，直接标「偏高」会被读成「回撤偏大」，故显示为「回撤较浅 / 回撤很深」；
  量比同理改为「显著放量 / 缩量明显」。
- 样本不足就明说。有效历史少于 250 点时显示「样本不足」，不编一个分位糊弄。
- 计算上完全复用因子实验室的因子函数，口径严格一致——两处数字打架是最难查的 bug。
- 纯本地库计算，不联网、不调大模型、不扣配额，单票 0.1~0.3 秒。

实测印证（贵州茅台 sh600519，2026-10-20）：20 日动量 +4.22%（83% 分位）、RSI 65.4
（95% 分位）、布林 %B 1.00 贴上轨（94% 分位）、MA20 乖离 +4.65%（94% 分位）——
五条独立指标互相印证「短线处于高位」，说明因子计算与分位映射都正确。

四、牛熊速查：把市场的冷热画成一根温度计

- 温度 0~100，由估值、情绪、资金、趋势等维度合成，一眼看出当下处在什么季节；
- 六档仓位映射，温度区间对应建议仓位区间，「冰点」与「沸点」不再是凭感觉的词；
- 历史序列：温度不是孤立的一个数，可以回看它一路怎么走到今天；
- 情绪面六维雷达：把构成温度的六个维度拆开画，能看出是哪一个在推着温度走。

五、昼夜双主题

- 白天 / 夜间一键切换，两套配色都是完整设计，不是简单反色；
- 图表、分层收益条、K 线、卡片阴影全部随主题联动；
- 默认白天（浅色）——白天盯盘时浅色更省神，夜里再切深色；

  圆角刻度统一到 2px 体系。

六、重要修复：推理模型导致全部 AI 功能降级

这一条值得单独说，因为它一度让所有 AI 功能看起来「全坏了」。

现象：个股深度分析、小白讲解、因子解读全部退化成一堆纯数据摘要，没有任何解读内容。
而且不是每次都坏——有时正常，有时坏，极难复现。

根因：接入的 Agents-A1 是思考型模型。它把推理过程塞进 message.reasoning_content，
真正的答案在 message.content；当 max_tokens 预算被思考吃掉时，content 直接为空，
上层拿到空字符串，便按「模型没给内容」的逻辑全部降级。

修复分三层：
- 默认在请求体带 chat_template_kwargs: {enable_thinking: false}，让模型直接出答案。
  实测复杂解读从分钟级降到 0.5~12 秒；
- 新增可配置开关 LLM_DISABLE_THINKING（后台「AI 模型」面板），换别的模型时可自行调整；
- 保留安全网：一旦检测到「content 为空 + 有思考内容 + 因长度截断」，自动放大 max_tokens
  重试，最多 3 次。这样即使换成别的推理模型、或用户手动打开了思考，也不会静默失败。
- 超时从 60 秒放宽到 120 秒，给足慢模型的时间。

另外修了两处：
- API 错误文案丢失 error 字段：前端请求封装在 4xx 时只读 detail / message / reason，
  漏了 error，导致因子实验室「数据不足」的 409 门禁说明退化成一句干瘪的「HTTP 409」。
  现在四者都读，用户能看到「池内有效截面仅 517 个交易日，需 ≥250」这类能指导下一步的提示。
- 牛熊速查页签点不到：页面存在但没进导航抽屉，属于「做好了却用不上」，已补进「📈 分析」分组。

八、升级说明

- 本版无需迁移数据库，直接拉取新版本重启即可；
- 若此前已在后台配好 AI 模型，升级后会自动启用「关闭思考」，无需手动调整；
  若换用非推理模型，可在「设置 → AI 模型」关掉该开关；
- 因子实验室首次计算需 5~10 秒（池子越大越久），之后 30 分钟内命中缓存秒开；
- 因子实验室需要本地已有日线数据，首次部署请先完成数据初始化。

九、边界与承诺

- 本版所有因子结论均为**统计口径的历史预测力**，不代表未来收益，不构成投资建议；
- 因子实验室与个股因子画像**不是同一件事**：前者算池内横截面 IC，后者算单票历史分位，
  两者不可互相替代，README 中有完整对比表；
- 因子的预测力会随市况衰减，今日「有效」的因子半年后可能失效。这张表给的是历史，
  不是承诺。
