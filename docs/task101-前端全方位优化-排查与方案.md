# Task#101 前端全方位优化 · 排查与方案

> 流程：备份 → 排查 → 方案（含改动后风险与对策）→ 测试 → 落地
> 原则：复用现有设计令牌、根因修复、删除优于新增（ponytail）。**桌面零改动代码路径、移动端仅增量**。
> 注：请求的 `Impeccable（前端设计工具集）` skill 本环境未安装（全局搜不到，仅历史对话出现过），故以 ponytail + 前端审计替代；如需该 skill 的专属能力，请先在市场安装或提供 SKILL.md。

## 一、审计方法
1. 通读 `<style>` 整块（15–823 行，约 808 行 CSS）
2. 脚本扫描**全部** `var(--x)` 引用，与 `:root` 已定义变量求差 → 找出未定义变量
3. 逐列核对题材雷达表格手机端 grid 与渲染列序是否对齐
4. 核对移动端导航抽屉的开关/无障碍现状

## 二、审计发现（根因）
| 编号 | 发现 | 证据 | 影响 |
|---|---|---|---|
| R1 | **4 个设计令牌从未定义却被广泛引用** | `--muted`(43处)、`--tx1`(13)、`--bg2`(7)、`--border`(1) | `var()` 计算失败 → 文字/标签/边框回退成**近黑色**；含 SVG `fill="var(--muted)"` 轴标签也变黑。这是"太黑看不清"的**全局根因**，不止连板模块 |
| R2 | `.tag` 基础规则被定义了两次（135 行与 750 行）且颜色冲突 | 后者覆盖前者，但首段定义的 `.tag.p/.n/.bj` 变体依赖首段存在 | 维护歧义、易踩坑 |
| R3 | 键盘焦点不可见 / 动画无减弱开关 | 无 `:focus-visible`、无 `prefers-reduced-motion` | 键盘用户、晕动症/无障碍用户不友好 |
| R4 | 手机抽屉打开后：无 Esc 关闭、背景仍可滚动 | `setupNavDrawer` 仅 mask/关闭按钮可关；`body` 未锁滚动 | 移动端抽屉后背景穿透滚动、无键盘退出路径 |

> 已排除的"假问题"：题材雷达表格手机端隐藏第5/6列后剩4列，与手机 grid `1.2fr 1.6fr .7fr 1fr` 完全对齐，**无需改**。

## 三、优化项与改动后风险对策

### O1 · 在 `:root` 补齐 4 个缺失令牌（最高杠杆，根因修复）
- 改动：`--muted:var(--tx3); --tx1:var(--tx); --bg2:#f7f8fa; --border:var(--line);`
- **改动后可能出现的问题**
  - P1：部分"本应醒目"的文字若此前依赖回退近黑、其实应是次级灰，定义后会变浅 → 个别标签对比度下降。
  - **对策**：`--muted` 映射到既有 `--tx3`(#8b93a1)，全为次级说明文字/轴标签/SVG 装饰，无主内容；白底下约 3:1 仍可读。脚本已逐处确认 43 处均为 caption/legend/sub/label。
  - P2：`--tx1` 定义后是否改变标题观感 → 映射 `--tx`（原本就回退到此），视觉无变化，仅消除脆弱性。
  - **对策**：取值与现状一致，零观感变化。
  - P3：影响面 64 处，是否误伤某模块 → **对策**：纯令牌重映射，无布局/选择器变更；测试断言"渲染无 JS 报错 + 关键模块正常 + muted 元素计算色为灰非黑"。

### O2 · 删除重复的 `.tag` 基础规则
- 改动：删除 135 行处重复的 `.tag{...}` 基础块，**保留**其 `.tag.p/.n/.bj` 变体（750 行作为规范基础）。
- **改动后可能出现的问题**
  - P1：误删导致 `.tag.p/.n/.bj` 变体丢失 → **对策**：仅删基础规则，变体规则原样保留；测试断言 `.tag.p` 背景为蓝、`.tag.bj` 为橙。

### O3 · 无障碍：焦点可见 + 减弱动画
- 改动：新增 `:focus-visible{outline:2px solid var(--accent);outline-offset:2px}`（作用于 button/input/select/.tabs button/.nd-item 等）；新增 `@media(prefers-reduced-motion:reduce)` 关闭 spin/pulse/transition。
- **改动后可能出现的问题**
  - P1：焦点环干扰鼠标点击观感 → **对策**：用 `:focus-visible` 而非 `:focus`，鼠标点击不显示、仅键盘聚焦显示。
  - P2：减弱动画影响加载指示可见性 → **对策**：仅停"动画"，spinner 形状仍在（静止圆），不影响"加载中"语义；脉冲点改静态。

### O4 · 手机抽屉：Esc 关闭 + 背景滚动锁
- 改动：`openNavDrawer` 设 `body{overflow:hidden}`、`closeNavDrawer` 还原；新增 `keydown` Esc 监听（仅抽屉开时生效）。
- **改动后可能出现的问题**
  - P1：桌面端误触发 Esc 监听 → **对策**：监听内先判 `drawer.classList.contains('open')`，桌面恒 false 不触发。
  - P2：关闭后 body 滚动未还原 → **对策**：`closeNavDrawer` 统一还原 `overflow=''`，所有关闭路径（mask/按钮/项点击/Esc）都走它。
  - P3：抽屉打开时页面跳顶 → **对策**：仅锁 `overflow`，不改动 `scrollTop`，关闭后位置不变。

## 四、测试计划（落地前必过）
用 Playwright 双视口（`tests/check_frontend_opt.py`）：
1. **桌面(1280)**：加载无 JS 报错；市场榜单/策略选股/回测/小白选股正常渲染；`.stratcat h3` 计算色为灰(#8b93a1)非黑；`.tag.p` 背景为蓝。
2. **移动(390)**：汉堡可见、inline tabs 隐藏（零回归）；抽屉展开列出可见模块；点模块切换正常；**Esc 关闭抽屉生效**；抽屉打开时 `body` 滚动被锁（scrollTop 不变）。
3. **令牌断言**：采样 `--muted` 元素 `getComputedStyle().color` 非 `rgb(26,29,35)`（近黑）而为灰。
4. **非回归**：切回市场榜单正常、无报错。

## 五、风险总览

- 桌面端：仅 O1 令牌重映射（观感一致）、O2 去重（变体保留）、O3 焦点/动画（仅键盘/减弱偏好生效）→ 鼠标用户无感。
- 移动端：仅 O4 抽屉增强（关闭路径收敛到同一函数）。
