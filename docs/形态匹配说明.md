> 借鉴 [Dzy-HW-XD/a-share-quant-selector](https://github.com/Dzy-HW-XD/a-share-quant-selector)
> 的 B1 完美图形匹配思路，**但原方案经本项目实测被否定，最终采用了修正方案**。
>
> 实现文件：`server/similarity.py`
> API：`GET /api/pattern_score`
> 策略 key：`pattern_score`（已注册进策略选股，共 16 个策略）
> 落地时间：2026-09-22

---

## 一、原方案是什么

参考项目的 B1 匹配：

```
人工挑 10 只历史成功案例
  → 提取四维形态特征（双线结构 30% / 量比 25% / 价格形态 DTW 25% / KDJ 20%）
  → 对当下全市场算相似度
  → 输出「最像历史牛股」的票
```

核心假设：**「和历史上的大涨股长得像的票，接下来也会大涨」**。

---

## 二、实测：这个假设在 A 股不成立

### 2.1 第一次验证：与模板比相似度，没有预测力

按原思路实现（模板取自「后 20 日涨 >15%」样本的中位形态），
在 300 只测试股上验证（训练集 300 只建模板，测试集 300 只验证）：

| 相似度分组 | 样本数 | 未来20日均值 | 胜率 |
|---|---|---|---|
| 高（≥70） | 9,702 | **+1.73%** | 47.2% |
| 中（50~70） | 37,597 | +1.51% | 50.2% |
| 低（<50） | 78,477 | **+1.77%** | **51.9%** |

**高相似度组与低相似度组几乎无差异（−0.04 个百分点），胜率反而更低。**

失败原因：模板取自「大涨之后回溯的中位形态」，而那个形态落在
**中高位（区间位置 0.62）**——本身就偏离了最优区间。

### 2.2 根因：A 股的强势形态是反向指标

在 250 只随机股票上，对比「后 20 日大涨(>+15%)」与「大跌(<-15%)」
**发生之前**的形态：

| 特征 | 大涨组 | 大跌组 |
|---|---|---|
| 前 60 日涨幅 | **+10.1%** | **+19.1%** |
| 前 60 日振幅 | 50.2% | 57.3% |
| 区间位置(0-1) | 0.49 | 0.55 |
| 量能比(近5/近60) | **1.05** | **1.25** |

**前 60 日涨得越多，未来越容易跌。** 这是 A 股均值回归特性的直接体现。
拿「已经暴涨的牛股」当模板，等于系统性地寻找最危险的票。

### 2.3 第二次验证：单特征在横截面上有强区分度

在 400 只股票、**167,721 个观察点**上做五分位分组（未来 20 日收益）：

| 特征 | 最低分位胜率 | 最高分位胜率 | 幅度 |
|---|---|---|---|
| 前 60 日涨幅 | **55.6%** | **40.5%** | +2.79 pt |
| 量能比 | **56.6%** | **44.3%** | +2.26 pt |
| 区间位置 | **58.5%** | **46.3%** | +2.20 pt |
| 前 60 日振幅 | 53.6% | 46.8% | +0.97 pt |

**方向高度一致：越低、越缩量、前期涨得越少 → 未来越容易涨。**

---

## 三、修正方案：按实测方向打分

放弃「与模板比相似度」，改为**对每个特征按实测的收益单调方向做分位打分**，
再加权合成 0~100 分。

### 3.1 权重（按实测区分幅度归一化）

| 特征 | 权重 | 方向 | 依据 |
|---|---|---|---|
| 前 60 日涨幅 | **0.34** | 越小越好 | 区分幅度最大（2.79 pt） |
| 量能比 | **0.28** | 越小越好 | 2.26 pt |
| 区间位置 | **0.27** | 越低越好 | 2.20 pt |
| 前 60 日振幅 | **0.11** | 越小越好 | 区分度较弱（0.97 pt），故权重低 |

> 对比参考项目的 30/25/25/20：本项目的权重来自**自己数据的实测区分度**，
> 不是沿用对方的经验值。振幅权重从 25% 降到 11% 就是因为实测区分度弱。

### 3.2 样本外验证：单调有效

在 400 只测试股上，按分数分组：

| 分数段 | 样本数 | 未来20日均值 | 中位 | 胜率 |
|---|---|---|---|---|
| **≥85** | 57,538 | **+2.93%** | +1.85% | **57.8%** |
| 75~85 | 25,438 | +2.00% | +0.77% | 53.1% |
| 65~75 | 21,636 | +1.67% | +0.12% | 50.3% |
| 55~65 | 19,035 | +1.44% | −0.33% | 48.6% |
| **<55** | 44,074 | **−0.07%** | −2.74% | **41.9%** |

**完全单调。** 最高分组 vs 最低分组：
- 均值差 **+3.00 个百分点**
- 胜率差 **+15.9 个百分点**

### 3.3 一个反直觉的细节

看「涨 >15% 占比」这一列会发现：**最低分组反而最高（14.7%）**，
最高分组只有 11.8%。

这不矛盾——**高波动 ≠ 高胜率**。低分组的票跌得多、弹得也猛，
但胜率只有 41.9%（多数时候在跌）。高分组的票是「稳稳地涨」，
很少暴涨但胜率高。

这恰好解释了原方案为何失败：**用「大涨」当正样本，收集到的是高波动特征，
而不是高胜率特征。**

## 四、API 用法

```bash
# 默认门槛 85 分
curl 'http://127.0.0.1:8899/api/pattern_score?limit=20'

# 调门槛（门槛 70 分时全市场约 61.8% 会入选，筛选意义不大）
curl 'http://127.0.0.1:8899/api/pattern_score?min_score=90'
```

门槛与命中数（实测，全市场 3761 只）：

| 门槛 | 命中数 | 占比 |
|---|---|---|
| ≥70 | 2323 | 61.8% |
| ≥80 | 1644 | 43.7% |
| **≥85** | **1247** | **33.2%** ← 默认 |
| ≥90 | 816 | 21.7% |
| ≥95 | 158 | 4.2% |

返回结构（每条）：

```json
{
  "code": "sz000682", "name": "东方电子",
  "score": 97.6,
  "score_parts": {"position": 99.5, "vol_ratio": 100.0,
                  "chg60": 96.9, "range60": 89.1},
  "feat": {"chg60": -14.4, "range60": 18.8,
           "position": 0.02, "vol_ratio": 0.63}
}
```

`score_parts` 是各维度 0~100 的得分，`feat` 是原始特征值。

## 五、作为策略使用

已注册为第 16 个策略（`pattern_score`），可与其它策略组合：

```bash
# 单独用
curl 'http://127.0.0.1:8899/api/strategy_scan?keys=pattern_score'

# 与「突破新高」取交集（低位滞涨 且 正在突破）
curl 'http://127.0.0.1:8899/api/strategy_scan?keys=pattern_score,breakout_20h&mode=intersect'

# 调门槛
curl 'http://127.0.0.1:8899/api/strategy_scan?keys=pattern_score&tune={"min_score":90}'
```

> 交集用法值得一试：「形态评分」找低位缩量的，「突破新高」找已经启动的，
> 两者的交集是「刚从低位启动」的票。

## 七、局限与后续

**必须说清楚的局限**：

1. **这是统计倾向，不是预测**。高分组胜率 57.8%，意味着仍有 42% 的时候不涨。
2. **只用了 2 年数据**（500 根）。更长的历史可能改变分位阈值。
3. **未纳入交易成本**。20 日 +2.93% 的均值，扣掉双边手续费与滑点后会更薄。
4. **未做行业/市值中性化**。「低位 + 缩量」可能只是某些板块的系统性特征，
   尚未验证剥离行业效应后是否依然有效。
5. **DTW 未实现**。参考项目用 DTW 做曲线形状匹配，本项目实测发现
   「形状相似」这个维度没有预测力（见 §2.1），因此没有实现。
   如果将来有更长历史，可以重新检验 DTW 在其它特征组合下的价值。

**可做的后续**：

| 优先级 | 动作 |
|---|---|
| P1 | 行业中性化：验证剥离行业后是否依然有效 |
| P2 | 加入更多特征（换手率、北向资金、波动率）并重算权重 |
| P3 | 用走查回测框架检验该评分的参数稳健性（`min_score` 是唯一的可调参数） |
| P4 | 若历史数据扩到 1000+ 根，重新标定分位曲线 |
